# Wedding Invitation

An elegant, modern, and highly interactive digital wedding invitation. 

## Features
- **Cinematic Entrance**: A dramatic gate opening sequence powered by CSS clip-paths and GSAP.
- **Scroll-Driven Physics**: Advanced "sticky-stacking" animations and blooming SVGs dynamically linked to the user's scrollbar.
- **High-End Typography**: Beautiful pairing of Imperial Script and Marcellus.
- **Micro-interactions**: Eased staggers, spring-physics countdowns, and "blur-to-focus" text reveals.

## Technology Stack
- Vanilla HTML / CSS / JS
- [GSAP (GreenSock Animation Platform)](https://gsap.com/)
- [Lenis Smooth Scroll](https://lenis.darkroom.engineering/)

## Local Development
To run this project locally, simply serve the directory with any local web server. For example:
```bash
npx serve .
```
Then open the provided `localhost` URL in your browser.

## Deployment
This project is optimized for deployment on Vercel. Simply import the repository or use the Vercel CLI:
```bash
npx vercel --prod
```
